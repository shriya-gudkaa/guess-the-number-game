# 🎲 Number Guessing Game

A simple and fun number guessing game built with **HTML, CSS, and JavaScript**.  
Guess the number between **1–20** within 5 attempts!

---

## 🚀 Features
- 🎯 Random number guessing  
- 💡 Hints (odd/even after 3 wrong tries)  
- 🏆 Score & High Score tracking  
- 🎨 Vibrant UI with responsive design  

---

## ▶️ How to Play
1. Enter your guess (1–20).  
2. Get feedback: Too High / Too Low.  
3. Use hints & beat the high score!
